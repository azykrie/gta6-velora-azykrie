**Velora City** — an original open-world crime game built for make.fun's "Make GTA 6" bounty. A sun-soaked coastal city to explore on foot and by car: steal cars, outrun the Velora PD under a 5-star wanted system, take on four story missions to pay off an $8,000 debt, and fight back with a pistol. Traffic, pedestrians, a live minimap, a save system and fully synthesised sound — all running offline from static files, no network, no assets but code.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Drive with W A S D, look with the mouse, E to steal a car, click to fire, M to start a mission.
